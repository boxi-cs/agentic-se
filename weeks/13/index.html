Agentic Software Engineering · Week 13

Keep the layers apart

Respond to findings and improve usability

9:23 · subtitles: English, 中文 · download

The idea

Keep the layers apart, and check each one on its own. A finding has three layers, observation, hypothesis and change, written in separate fields. A generated change is a claim until one task check runs on the page: proposal A looks right (labelled, reached by keyboard, query check green) and does not help, because its selection never reaches the query. Each check answers only its own question (the query check, the request line, the keyboard walk, a new authorized session), and the iteration is accepted only for the checked scope. M4 turns each Week 12 result into the response that result selects, and a repair starts with a test that fails on the frozen snapshot. Across an organization the same separation holds: the portal's grants, the gateway's key and budgets, the cost of an accepted change and the evaluator that routing depends on are separate layers, each checked on replayed records, generation first, then verification. The demo shows the same moves in eight minutes.

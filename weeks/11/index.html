Check the summary

9:26 · subtitles: English, 中文 · download

An agent's summary of its own work is a claim. Before acting on it, check it against the record the team keeps. The film does that six times: on a tool portal's grants, a model gateway's runs, the cost of an accepted change, a routing choice, a draft root-cause analysis and a proposed repair. The budget rule sits between the gateway and the cost, because run R3 of the gateway record is that rule at work.

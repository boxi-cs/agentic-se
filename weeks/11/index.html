Agentic Software Engineering · Week 11

A timeout is not nothing

Recover a user path after an incident

6:03 · subtitles: English, 中文 · download

The idea

A timeout marks where observation stopped; it does not prove nothing happened. Walk the event chain to find the observation that separates a lost reply from a failed commit (the persisted job and its operation key); repair at the persistence boundary with an operation key; write the replay predictions and a rollback condition before changing anything; and declare recovery only when the user can see the required state and duplicates are excluded for the tested path. A model gateway's budget follows the same rule: a lost reply keeps its whole reservation.

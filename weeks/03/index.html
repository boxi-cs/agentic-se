Change only the context

Find the change in an unfamiliar repository

5:56 · subtitles: English, 中文 · download

The idea

Context is an intervention you can test. Trace the request path first, so the context you give an agent is the task, the call-path excerpt, the contract and the failing case; then compare two contexts on the same task by changing the context only, with the model, task, fresh start, one-call budget and verifier fixed. Predict before running; record what was observed, including cost; and claim no more than one paired run shows.

This week

Lecture
Trace one dashboard request across files; select context and a bounded edit; compare two context packets.
Workshop
Map a ci-dashboard call path, compare fixed-budget contexts, check one permission boundary, use one standard skill on ci-dashboard and carry it read-only to an unfamiliar permissively licensed open-source repository.
Deliverables
Repository-context workshop; start M0

Agentic Software Engineering · Week 3

Change only the context

Find the change in an unfamiliar repository

9:27 · subtitles: English, 中文 · download

The idea

An agent acts only on what reaches it, so the context is an intervention you can test (notes:21-23). Trace the request path first; then compare contexts on the same task by changing the context only, with the question, the model, a fresh call, one call each and the checker fixed. Predict before running, keep predictions apart from what was observed, and claim no more than one pair shows (notes:73-84, :118-121, :607). The same holds in the middle of a session: build the next request four ways from one long history, run the same check on each, and check a summary against the transcript as well as by the next check (notes:182-255).

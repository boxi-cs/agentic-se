The near miss

7:05 · subtitles: English, 中文 · download

A skill’s description is ready when you have tried three requests that should trigger the skill and one similar request that should not (a near miss), and all four behaved as you predicted in a run you saved. Checking the skill’s files cannot show this: it cannot see which skill the agent picked.

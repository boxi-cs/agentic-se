Agentic Software Engineering · Week 4

Not passed is not failed

Turn a user need into an executable specification

6:06 · subtitles: English, 中文 · download

The idea

A requirement has to be traced from an observed event, not invented in the request. Ask about a past event; keep observation, inference and what you cannot conclude apart; write the problem statement by hand and check each clause against the observation; write an acceptance criterion that labels its design choices; then judge a generated candidate against that criterion. The trace runs S4-A → P1 → AC1 → AC1-mixed → predicate repair, and a passing test cannot turn a design choice into user evidence.

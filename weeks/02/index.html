Agentic Software Engineering · Week 2

Done is a claim

Build and inspect a small agent

9:37 · subtitles: English, 中文 · download

The idea

An agent record that says read, write, then "done" with no further calls does not show that the bug is fixed. Report verified only when a passing check appears after the last write; the stop reason (final or step_limit) is reported separately, and a summary of the run is a claim too: it must keep the last failed check and be checked against the transcript (notes:56-68, :221-228).

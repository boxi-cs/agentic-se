Four places to lose a rule

8:48 · subtitles: English, 中文 · download

A rule can get lost on the way from research to plan, code and checks. A plan is complete only when the rule, where it came from, where it applies in the code and one case it must refuse all reach verification. Before a long session is shortened, write the rule and its source into a handoff and check the handoff against the record.

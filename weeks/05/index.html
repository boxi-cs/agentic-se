Shorter, same contract

Deliver a small change without breaking callers

5:57 · subtitles: English, 中文 · download

The idea

A shorter refactor still has to keep the behavior callers rely on. First freeze that behavior in characterization tests. Then make one structural change and run the same tests unchanged. A structural count (fewer if statements) cannot tell a broken refactor from a working one.

This week

Workshop
Start M1; CP1 is a 30-minute individual diagnosis, test and repair after practice.

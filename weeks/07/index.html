Would the tests notice?

9:51 · subtitles: English, 中文 · download

A green test run is evidence only for the faults its tests could have noticed. A surviving mutant (a small planted bug the tests missed) shows which test is missing. A property test covers only the inputs it generates, so keep its shrunk counterexample as a regression test. A patch that lets a caught mutant survive again has weakened the tests, whatever its summary says.

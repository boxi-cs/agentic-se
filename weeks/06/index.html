Review before you ask

Made for the earlier edition of this course, which ran model-written code through a course launcher. The current course does not require one.

9:37 · subtitles: English, 中文 · download

Review a change against what was asked, before you ask anyone else. Write your own review first, name a concrete input and reproduce the failure. Only then read a model's review, whose points are hypotheses: mark each one confirmed, refuted or cannot tell with its evidence. A revision is accepted on the unchanged checks, not on how clear it looks.

Agentic Software Engineering · Week 12

The observation decides

Verify a model audit with reproducible evidence

9:22 · subtitles: English, 中文 · download

The idea

A recorded model review is a set of claims, and the observation decides each one. Label a clean, frozen snapshot and its requirements before reading the review; turn each claim into a check and an input you choose yourself; write the prediction, then run the check and record the command it prints. A claim's wording sets what one run can decide (one input, some input, every input, each member of a listed set, something outside the snapshot): an unfinished search is not a disposition, an overstated claim is split into parts, and cannot tell (undetermined in the record) names what the snapshot lacks. Reviews over-assert and miss sibling paths, so add one check of your own or bound a clean range. The verifier reruns every check and derives the supported disposition from the observation; it never calls a model. Each claim ends confirmed, refuted or cannot tell, judged against the frozen requirements, not the wording of the review. M3 runs the same sequence on the student's own tag.

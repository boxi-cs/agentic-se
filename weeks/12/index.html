Agentic Software Engineering · Week 12

The observation decides

Verify a model audit with reproducible evidence

6:22 · subtitles: English, 中文 · download

The idea

A recorded model review is a set of claims. Freeze and label the snapshot before reading it, read the rule as written and predict each check, then run it: the runnable observation on that snapshot decides confirmed, refuted or undetermined, and an undetermined row names the missing input. Reviews over-assert (a salient token, ignored precedence, a filled-in missing file) and miss paths, so add one check the review did not make, or bound a clean path. Write each row in one shape and let the verifier rerun it; it rejects an unsupported disposition or a hand trace in place of a command, and never calls a model. A successful command supports only the path and revision it exercised.

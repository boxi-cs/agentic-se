Agentic Software Engineering · Week 10

The scorer said pass

Test the evaluator and build a regression gate

9:26 · subtitles: English, 中文 · download

The idea

An evaluator is an instrument, and its verdicts are claims until the instrument itself has been challenged. Freeze the contract (request, environment, stop, score) before reading the scorer; challenge the scorer with right, wrong, missing, persuasive and case-variant answers; verify a bounded repair with the unchanged cases and state what that pass does not cover; keep completion separate from correctness; choose the simplest grader that can decide; challenge a judge with labels fixed first, adversarial cases included, because one false accept makes it unfit for a gate; read the confusion table, not only kappa; make the regression gate able to fail on five conditions, with the expected case count pinned, not counted; freeze the M2 technical snapshot on the path changed in M1.

Agentic Software Engineering · Week 14

Has it ever failed?

Demonstrate and defend the result

6:36 · subtitles: English, 中文 · download

The idea

Claim only the scope you checked, and trust a check only once you have seen it fail. The practice packet's code predicts that a guest is denied, but the evidence matrix never observed a guest, so acceptance extends only to cases that were checked. Our scratch run of Snapshot B's lines shows the guest cases behaving as predicted, and a deliberately broken variant shows the check can fail; it still supports only those lines, not the request and stored title. A changed condition in rehearsal (a role policy, an output format, a timeout) needs its own evidence, and a demo keeps its failures. The same rule decides the software-factory claim stage by stage: a stage may run unattended only with a check seen to fail on a bad input and pass on a good one, and a stop path someone has exercised.

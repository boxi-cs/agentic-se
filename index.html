Agentic Software EngineeringBuild, verify, evaluate.

Learn to enter an unfamiliar repository, clarify a requirement, use an agent for a bounded task and decide whether the evidence supports the change. The teacher's CI dashboard case grows from a status error into a reviewed, evaluated and operated product. Each student works in their own copy of the ci-dashboard repository and delivers one complete feature.

  • 14 weeks
  • 3 personal practices
  • 5 project workshops
  • 1 repository, ci-dashboard

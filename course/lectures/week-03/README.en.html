    Week 3: Agent skills and the CLI

    This folder teaches one repeatable loop: run a workflow by hand, encode it as a SKILL.md, test three expected triggers and one near miss, then preserve the evidence from the command-line runs. The studio prepares A3 and its accept/narrow/recheck/stop decision line.

    Start with notes, use the direct checker command in activities, and finish with the self-check. The readings name the course-authored skill examples and the checker. The checker is fixture/skill_check.py.

# Agentic Software Engineering — course site

The public site for *Agentic Software Engineering: Build, Verify, Evaluate*, served by GitHub Pages at
<https://boxi-cs.github.io/agentic-se/>.

It has a home page (overview, schedule, videos, teaching team), an approach page, the syllabus, and one page
per calendar week (`weeks/01` … `weeks/13`: twelve teaching weeks and the assessment week) with that week's
topic, first session (lecture), second session (guest or studio), what is due, links to the week's materials
and any film that supports it. `course/` holds the full student materials: the course repository's own
English student site (notes, slides, activities, readings, self-checks, assignments, project, rubrics and
policies).

## How it is built

The pages are static HTML generated by `build.py` (Python 3.10+, standard library only) from three data files:

- `data/course.json`: the course's public English overview, calendar and English syllabus
  (`SYLLABUS.en.md`, which must match its Chinese source; any edit for a public page is listed in
  `tools/export_data.py`, and there are none at present);
- `data/episodes.json`: each film's number, title, idea, length and subtitles;
- `data/films.json`: which calendar week each film supports and whether the site publishes it.

The first two are exported from the private course and video repositories, and record the commit they were
read from. `build.py` writes one week page per row of the calendar, takes each page's materials links from the
course's own week overview page under `course/` (so only pages that exist are linked), checks every local
link on the pages it writes, and stops if a page names a film that is not published.

### Films

The course has twelve teaching weeks and an assessment week, and each film is made for one teaching week.
A film's slug starts with its week number (`03-the-near-miss` is the Week 3 film). `data/films.json`,
maintained by hand, says which calendar week each film appears under and whether the site publishes it.
Each film slug has:

- `week`: the calendar week it supports (`null` while it is not published);
- `published`: `true` or `false`;
- `withheld_reason`: one sentence, required when `published` is `false`.

There are twelve films today, one for each of weeks 1–12, and all are published. Week 13 is assessment
and has no film.

A published film appears on its week's page and on the home page. Its poster and subtitle tracks live in
`films/<slug>/`. A film that is not published is not linked, embedded or listed anywhere, and `build.py`
removes its folder from `films/`. `data/films.json` may also carry an `edition_note`, one sentence that
`build.py` then shows under every film's title; there is none at present.

The video files are assets of the
[`videos-2026-10-13` release](https://github.com/boxi-cs/agentic-se/releases/tag/videos-2026-10-13),
named `week-NN.mp4` after the first two digits of the film's slug, so the repository stays small.

To republish a film after it is re-rendered (its change is merged in the video repository and the new
render is in that repository's `media/episodes/<slug>/`):

1. copy its `Episode.mp4` to `week-NN.mp4` and upload it to the release in place of the old asset
   (`gh release upload videos-2026-10-13 week-NN.mp4 --clobber --repo boxi-cs/agentic-se`);
2. run `git fetch` in the video repository's clone: `tools/export_data.py` reads its `origin/main` and
   does not fetch it;
3. re-run `tools/export_data.py`, `tools/posters.py` and `build.py` (the commands below), and commit.

If a film's slug changes, give the new slug its week in `data/films.json` and remove the old one:
`build.py` stops if `data/films.json` and `data/episodes.json` name different films.

```sh
python3 tools/course_site.py --course ../agentic-se-course    # course/: the course's own English student site
python3 tools/export_data.py --course ../agentic-se-course --videos ../agentic-se-videos   # data/course.json, data/episodes.json
~/Documents/agentic-se-videos/.venv/bin/python tools/posters.py --videos ../agentic-se-videos   # films/<slug>/poster.jpg
python3 build.py              # index.html, approach/, syllabus/, weeks/NN/, films/<slug>/*.vtt
python3 -m http.server   # preview at http://127.0.0.1:8000/
```

Run `tools/course_site.py` before `build.py`: the week pages read `course/`.
`build.py` also writes the root `404.html` (GitHub Pages shows it for every missing path, so its links
start at `/agentic-se/`) and checks the local links of every page, `course/` included.

To preview a course branch before it is merged, pass `--ref <branch>` to `tools/course_site.py` and
`tools/export_data.py`; publish only what was built from `origin/main`.

The films are narrated in English with a draft synthetic voice (`en_US-ljspeech-high`, trained on the
public-domain LJ Speech data). Every example in them is course-authored and synthetic.

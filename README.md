# Agentic Software Engineering — course site

The public site for *Agentic Software Engineering: Build, Verify, Evaluate*, served by GitHub Pages at
<https://boxi-cs.github.io/agentic-se/>.

It has a home page (overview, weekly videos, schedule, teaching team), the syllabus, and one page per week with that
week's film, English and Chinese subtitles, the idea it teaches and the week's lecture, workshop and
deliverables. `course/` holds the full student materials: the course repository's own English student site
(notes, slides, activities, readings, self-checks, practices, project, rubrics and policies).

## How it is built

The pages are static HTML generated by `build.py` (Python 3.10+, standard library only) from two data files:

- `data/course.json`: the course's public English overview, 14-week schedule and English syllabus
  (`SYLLABUS.en.md`, which must match its Chinese source; two small edits for a public page are listed in
  `tools/export_data.py`);
- `data/episodes.json`: each weekly film's title, idea, length and subtitles.

Both are exported from the private course and video repositories, and record the commit they were
read from. The films themselves are assets of the
[`videos-2026-10-08` release](https://github.com/boxi-cs/agentic-se/releases/tag/videos-2026-10-08),
so the repository stays small.

```sh
python3 tools/course_site.py --course ../agentic-se-course    # course/: the course's own English student site
python3 tools/export_data.py --course ../agentic-se-course --videos ../agentic-se-videos
~/Documents/agentic-se-videos/.venv/bin/python tools/posters.py --videos ../agentic-se-videos   # weeks/NN/poster.jpg
python3 build.py
python3 -m http.server   # preview at http://127.0.0.1:8000/
```

The films are narrated in English with a draft synthetic voice (`en_US-ljspeech-high`, trained on the
public-domain LJ Speech data). Every example in them is course-authored and synthetic.
